# Documentation Assets

This directory contains static assets for documentation.

## Contents

Place the following types of files here:

- Images (PNG, JPG, SVG)
- Diagrams
- Screenshots
- Other static resources

## Usage in VitePress

Reference assets in markdown files using relative paths or the `/assets/` prefix.

## Diagram Guidelines

- Use **Mermaid** for code-based diagrams when possible
- Export complex diagrams as SVG for better quality
- Keep image file sizes optimized
