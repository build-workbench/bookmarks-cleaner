# 浏览器书签管理的最佳实践

在信息爆炸的时代，浏览器书签是我们导航数字世界的个人地图。然而，一个杂乱无章、缺乏维护的书签库不仅会降低我们寻找信息的效率，更会成为一种心理负担。

CleanBook 旨在通过自动化的方式解决书签"熵增"的问题。这份文档将提供一套从日常习惯到工具使用，再到高级技巧的最佳实践，帮助您建立一个高效、有序且真正服务于您的个人知识库。

---

## 黄金四原则：养成高效的书签习惯

### 1. 精挑细选，果断"断舍离"

**原则：** 书签是用来"参考"的，不是用来"收藏"的。

在点击"收藏"按钮前，问自己一个问题："**一个月后，我真的会再次访问这个页面吗？**"

- **只存常访问的：** 只为那些您确定会反复访问的网站、工具或文档建立书签
- **区分"待办"与"参考"：** 如果链接只是需要稍后阅读，请使用 Pocket 等稍后阅读服务，而非污染您的参考库
- **避免"情感收藏"：** 很多时候我们收藏只是因为"看起来可能有用"，但 99% 不会再被打开，果断放弃它们

### 2. 智能命名，方便未来搜索

**原则：** 书签的名称是为您自己服务的，而不是为网站服务的。

永远不要满足于网站的默认标题，尤其当它含糊不清时（如"首页"、"登录"）。

- **格式统一：** 采用固定的命名格式，如 `[项目/主题] - [具体内容]`
  - ❌ `Dashboard`
  - ✅ `[工作] - LUSH 项目管理面板`
  - ❌ `The Illustrated Word2vec`
  - ✅ `[AI] - 图解 Word2vec (Jay Alammar)`
- **关键词前置：** 将最重要的关键词放在名称开头，方便快速识别和搜索

### 3. 逻辑分组，构建清晰结构

**原则：** 一个好的文件夹结构，本身就是一种高效的索引。

- **顶级分类要少而精：** 顶级文件夹建议控制在 5-7 个，例如：`01_工作`、`02_技术栈`、`03_学习资料`、`04_效率工具`、`05_生活服务`。使用数字前缀固定顺序
- **层级不宜过深：** 尽量保持 2-3 层结构深度。如果能无限细分，说明可能需要重构
- **CleanBook 自动化辅助：** 根据您在 `config.json` 中定义的规则，自动完成逻辑分组

### 4. 定期回顾，保持动态平衡

**原则：** 书签库是一个"活"的系统，需要新陈代谢。

- **设置提醒：** 每隔 2-3 个月，花 15-30 分钟快速浏览一遍书签
- **大胆删除：** 删除项目已结束、技术已过时、或者您已经掌握了的链接
- **检查坏链：** 使用浏览器扩展查找并清理无法访问的死链接

## 配置 CleanBook：建立您的分类体系

### 第一步：确定您的主分类

在 `config.json` 中定义顶级分类。建议从以下维度思考：

| 维度 | 示例分类 |
|------|----------|
| 工作项目 | 工作台、内部系统 |
| 技术领域 | AI/ML、编程、生物信息 |
| 学习资源 | 教程、课程、文档 |
| 工具集合 | 在线工具、效率软件 |
| 个人兴趣 | 阅读、娱乐、生活 |

### 第二步：定义分类规则

为每个分类添加识别规则：

```json
{
  "category_rules": {
    "人工智能": {
      "rules": [
        {
          "match": "domain",
          "keywords": ["openai.com", "huggingface.co", "arxiv.org"],
          "weight": 15
        },
        {
          "match": "title",
          "keywords": ["GPT", "LLM", "神经网络", "深度学习"],
          "weight": 10
        }
      ]
    }
  }
}
```

### 第三步：维护受控词表

在 `taxonomy/subjects.yaml` 中维护主题词表：

```yaml
preferred: "人工智能"
variants:
  - "AI"
  - "机器学习"
  - "深度学习"
```

## 推荐工作流

### 月度整理工作流

1. **导出书签**：从浏览器导出 HTML 格式书签
2. **放入工作目录**：将文件放在项目目录或自定义位置
3. **一键执行**：
   ```bash
   cleanbook -i chrome_bookmarks.html -o output
   ```
4. **分析新生事物**：查看 `output/` 下的 Markdown 报告，识别未分类的书签
5. **调优配置**：发现新的域名/关键词模式时，更新 `config.json`
6. **导入成品**：将整理好的 HTML 导入干净的浏览器文件夹

### 增量维护工作流

对于日常新增的书签：

1. 使用浏览器插件或快捷键临时收藏
2. 每周运行 CleanBook 处理新增书签
3. 将分类好的书签导入主书签栏
4. 删除临时收藏

## 高级技巧

### 地址栏关键词搜索

顶级效率技巧。为常用书签设置关键词：

**Chrome/Edge 设置方法：**
1. 打开书签管理器 (Ctrl+Shift+O)
2. 找到目标书签，右键 → 修改
3. 在"网址快捷方式"字段设置关键词，如 `gh`
4. 之后在地址栏输入 `gh` 回车即可跳转

**推荐关键词设置：**
| 关键词 | 目标 | 使用场景 |
|--------|------|----------|
| `gh` | GitHub | 快速访问代码仓库 |
| `doc` | 团队文档 | 打开内部文档站 |
| `mail` | 邮箱 | 打开邮件系统 |

### 巧用 JavaScript 小书签 (Bookmarklets)

将 JavaScript 代码保存为书签，点击即可在当前页面执行操作：

```javascript
// 示例：提取页面所有图片
javascript:(function(){
  var imgs = document.querySelectorAll('img');
  var urls = Array.from(imgs).map(img => img.src);
  prompt('图片链接', urls.join('\n'));
})()
```

### 浏览器内置搜索技巧

- 在地址栏输入 `*` + `空格` + `关键词` 可仅搜索书签
- 这比在历史记录中查找快得多

## 分类设计建议

### 两层的分面分类

CleanBook 推荐使用 `subject -> resource_type` 两层结构：

```
人工智能/                ← subject（主题）
├── documentation/       ← resource_type（资源类型）
├── code_repository/
├── video/
└── article/
```

### 常见 Resource Type 分类

| 类型 | 说明 | 示例 |
|------|------|------|
| `code_repository` | 代码仓库 | GitHub、GitLab |
| `documentation` | 官方文档 | API docs、Wiki |
| `article` | 文章博客 | 技术博客、新闻 |
| `video` | 视频资源 | YouTube、B站 |
| `tool` | 在线工具 | 在线编辑器、计算器 |
| `course` | 课程教程 | 在线课程、MOOC |
