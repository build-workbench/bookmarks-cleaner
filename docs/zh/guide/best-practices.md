# 最佳实践

书签管理和分类的最佳实践指南。

## 分类策略

### 1. 从宽到严

刚开始使用时建议：
- 降低置信度阈值（0.5-0.6），获得更多分类
- 根据结果调整规则，提高覆盖率
- 稳定后再提高到标准阈值（0.7）

### 2. 保持简洁

- 主分类建议 8-12 个
- 避免过细的子分类
- 定期合并相似的分类

### 3. 命名规范

- 使用简洁的名称
- 添加 emoji 便于识别
- 统一命名风格

## 维护策略

### 定期清理

```bash
# 添加到 crontab
0 2 * * 0 cleanbook -i ~/bookmarks.html -o ~/bookmarks-clean/ --train
```

### 版本备份

```bash
# 清理前备份
cp bookmarks.html bookmarks-$(date +%Y%m%d).html
```

## 性能优化

1. **首次使用**: 使用 `--train` 训练 ML 模型
2. **大批量处理**: 增加 `--workers` 数量
3. **内存受限**: 使用 `--no-ml` 和 `--workers 1`
