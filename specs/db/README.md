# Database Schema Specifications

This directory contains database schema definitions.

## Planned Contents

- `schema-v1.dbml` - Database schema definition in DBML format
- `migrations/` - Database migration scripts

## Current Status

The CleanBook system currently uses file-based storage (JSON/HTML) without a traditional database. Database schema specifications will be added when persistent storage is implemented.
